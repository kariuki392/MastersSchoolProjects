## 1. Linear and Non-Linear Models

### Project Overview
This module focuses on the theory and application of classical linear regression, with particular emphasis on the systematic verification of model assumptions and the interpretation of diagnostic results.

### Notebooks and Supporting Materials

#### STA6110Z_Kariuki_Gabriel_Wk4a.ipynb  
**Assignment 3: Regression Assumptions and Diagnostics**

This notebook presents a complete diagnostic analysis of a simple linear regression model in which Disease Progression Score is regressed on Body Mass Index (BMI) using the Diabetes dataset of Efron, Hastie, Johnstone and Tibshirani (2004) (n = 442).  

The analysis proceeds through the following stages:
- Model estimation via ordinary least squares
- Assessment of linearity
- Evaluation of homoscedasticity (including the Breusch-Pagan test)
- Examination of residual normality
- Assessment of residual independence
- Identification of influential observations and high-leverage points

All diagnostic plots and numerical tests are generated programmatically and are aligned with the structure of the accompanying formal report.

**Required environment**  
Python ≥ 3.9, together with the packages `numpy`, `pandas`, `matplotlib`, `scipy`, `statsmodels`, and `scikit-learn`.

#### MDA6110_Assignment2_Kariuki_Gabriel.ipynb  
This notebook contains the primary analytical work for the Diabetes regression assignment, including exploratory data analysis, model fitting, and supporting computations that underpin both the diagnostic notebook and the written report.

**Required environment**  
Identical to that specified for `STA6110Z_Kariuki_Gabriel_Wk4a.ipynb`.

#### STA6110ZWk4Assignment_Kariuki_Gabriel.docx  
Formal written report presenting the model results, assumption checks, diagnostic findings, and substantive conclusions.

## 2. Time Series Analysis

### Project Overview
This module addresses the fundamental techniques of time-series analysis, including tests for stationarity, seasonal decomposition, autocorrelation and partial autocorrelation analysis, and the specification and estimation of Seasonal Autoregressive Integrated Moving Average (SARIMA) models.

### Notebooks and Supporting Materials

#### STA6130_Week3_AirPassengers_Analysis.ipynb  
**STA6130 Week 3 Group Assignment: Differencing, Autocorrelation and Partial Autocorrelation**

The notebook analyses the classic AirPassengers series (monthly international airline passengers, January 1949 – December 1960). In the interest of pedagogical transparency, the Augmented Dickey-Fuller test, the sample autocorrelation function, and the sample partial autocorrelation function are implemented from first principles using only NumPy and pandas.  

Successive differencing strategies are examined, culminating in the recommendation of a SARIMA(0,1,1)(0,1,1)₁₂ specification as a suitable starting model.

**Required environment**  
Python ≥ 3.9 with `numpy`, `pandas`, and `matplotlib`. No external time-series libraries are required.

#### uscandyproduction.ipynb  
This notebook applies a parallel analytical workflow to the United States Candy Production Index. It encompasses seasonal decomposition, stationarity testing, ACF/PACF examination, SARIMA model estimation, residual diagnostics, and multi-step forecasting. The majority of the figures contained in the `imagesandreport` directory are generated by this notebook.

**Required environment**  
Python ≥ 3.9 together with `numpy`, `pandas`, `matplotlib`, and `statsmodels`.

#### sarima_engine.py  
A modular helper script that encapsulates routine SARIMA fitting, residual checking, and forecasting procedures, thereby promoting code reuse and clarity within the Candy Production analysis.

#### results.json  
A structured record of key numerical outputs (selected model orders, information criteria, and forecast accuracy metrics) produced during the SARIMA modelling process.

#### candy_production.csv  
The source data file containing the monthly United States Candy Production Index series.
